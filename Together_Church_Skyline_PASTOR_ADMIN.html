How to use the system

  • Directory — add, edit, search, and delete member records.
  • Prayer Wall — submit and update prayer requests.
  • Calendar — create church events and schedules.
  • To Do's — assign tasks and mark them complete.
  • Attendance — check members in and out.
  • Giving — record donations for local reporting.
  • Resources — save links and small files.

Important: this standalone HTML version saves data in this browser only. For shared accounts, real Gmail/Facebook login, email delivery, cloud backup, and multi-device access, connect a secure backend.
